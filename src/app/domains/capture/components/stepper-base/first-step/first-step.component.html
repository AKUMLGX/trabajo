Incio del Proceso de Búsqueda
Para iniciar el flujo de captura, utilice la función de búsqueda introduciendo cualquiera de los siguientes datos:
  1. ✔ Folio interno
  2. ✔ Oficio
  3. ✔ Persona relacionada
  4. ✔ Carpeta de investigación
Haga clic en el icono de la lupa para buscar registros existentes. Esta búsqueda le ayudará a determinar si ya hay información en el sistema que se relacione con el caso que está manejando, lo cual es fundamental para mantener la eficiencia del sistema y prevenir el registro de información duplicada.
Instrucciones:
  1. 1. Ingrese el dato correspondiente en el campo de búsqueda.
  2. 2. Examine los resultados.
  3. 3. En caso de encontrar un caso relacionado, selecciónelo para agregar la información a su gestión actual.
  4. 4. Si no se identifica un caso relacionado, puede continuar al siguiente paso para registrar un nuevo caso haciendo clic en 'Siguiente'.
